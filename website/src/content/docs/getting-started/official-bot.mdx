## Commands

| Command | What it does |
| --- | --- |
| `/play query [next]` | Play a song, playlist or link, with suggestions as you type |
| `/nowplaying` | Bring the player to the bottom of the chat |
| `/pause` · `/resume` | Pause or resume |
| `/skip [to]` · `/previous` | Skip, jump to a song in the queue, or go back |
| `/seek time` | `1:30`, `90`, `2m`, `+10` or `-10` |
| `/queue` · `/remove` · `/move` · `/shuffle` | Manage the queue |
| `/loop [mode]` · `/autoplay` | Loop the song or queue, keep playing related songs |
| `/volume [level]` · `/filters [preset]` | Volume (0-200), bass boost, nightcore, 8D and more |
| `/lyrics` | Lyrics of the current song (needs LavaLyrics) |
| `/stop` · `/help` · `/ping` | Stop and leave, open the help menu, or check latency |
| `/stats` | Bot, player and music server numbers |
| `/setup` · `/dj` | Server managers only: create the request channel with a live dashboard, or pick who may control the music |
| `/reset` · `/summon` | Server managers only: force the player to stop, or move the bot to your channel |

Only people in the bot's voice channel, or members who can manage the server, can control the music. With `/dj set`, skips, stops and sound changes are limited to that role, while everyone can still add songs. Anyone can look at the queue.

## Run it yourself

You need Node.js 20.12+ and a [Lavalink v4 server](../installation/).

<Steps>

1. Clone the repository, build raya.js and install the bot:

   ```bash
   git clone https://github.com/neuzgg/raya.git
   cd raya
   npm install && npm run build
   cd bot && npm install
   ```

2. Create an application in the [Discord Developer Portal](https://discord.com/developers/applications) and copy the bot token. No privileged intents are needed.

3. Copy `bot/.env.example` to `bot/.env` and fill in `DISCORD_TOKEN` and your Lavalink details.

   <Aside type="caution">`bot/.env` is gitignored. Never put your token in `.env.example` or any other file you commit.</Aside>

4. Register the slash commands and start the bot. It prints an invite link:

   ```bash
   npm run deploy
   npm start
   ```

</Steps>

To restart without stopping the music, press `Ctrl+C` and start the bot again within a minute. Players are saved and picked up automatically ([how restarts work](../../guides/restarts/)).

## Make it yours

- **Emojis** are in `src/ui/emojis.js`. Swap in your own application emojis as `<:name:id>`.
- **Every message** is built with one `card()` helper in `src/ui/components.js`, so the look stays consistent.
- **The help menu** takes its categories and command rows from `src/commands/catalog.js`, and its news from `src/announcements.js`.
- **The player** lives in `src/ui/panel.js`, and `src/music/panels.js` keeps one live player message per server.
- **Tests** check every card against the design rules and run full `/play` → button flows against a Lavalink simulator: `npm test`.
