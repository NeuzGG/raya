## Commands

| Command | What it does |
| --- | --- |
| `/play query [next]` | Play a song, playlist or link, with suggestions as you type |
| `/nowplaying` | Bring the player to the bottom of the chat |
| `/pause` · `/resume` | Pause or resume |
| `/skip [to]` · `/previous` | Skip, jump to a song in the queue, or go back |
| `/seek time` | `1:30`, `90`, `2m`, `+10` or `-10` |
| `/queue` · `/remove` · `/move` · `/shuffle` | Manage the queue |
| `/loop [mode]` · `/autoplay` | Loop the song or queue, keep playing related songs |
| `/volume [level]` · `/filters [preset]` | Volume (0-200), bass boost, nightcore, 8D and more |
| `/lyrics` | Lyrics of the current song |
| `/stop` · `/help` · `/ping` · `/stats` | Stop and leave, open the help menu, check latency or see the numbers |
| `/setup create` · `/setup delete` | Server managers only: make the song request channel, or delete it again |
| `/dj set` · `/dj clear` | Server managers only: pick who may skip, stop and change the sound |
| `/reset` · `/summon` | Server managers only: force the player to stop, or move the bot to your channel |

Only people in the bot's voice channel, or members who can manage the server, can control the music. With `/dj set`, skips, stops and sound changes are limited to that role, while everyone can still add songs. Anyone can look at the queue.

## Set up a song request channel

<Steps>

1. Invite the bot with the button above, so it can create channels and speak in voice.

2. Run `/setup create`. Raya makes a **Raya Music** category with a `#raya-requests` channel and a voice channel, and posts the dashboard there.

3. Join the voice channel and type a song name or paste a link in `#raya-requests`. The request is tidied away and the dashboard turns into the player.

   <Aside type="tip">Music commands then only work in that channel, so the rest of the server stays quiet. `/setup disable` lifts that, `/setup delete` removes the channels.</Aside>

</Steps>
