Mix presets and effects. The lab uses the same math as Raya's `Filters` class, so the **Sent to Lavalink** panel shows what the player really sends. Filters that are off are left out of the payload.

<FilterLab />

- `bassBoost` only changes bands 0-4, so it layers on top of any equalizer preset.
- Nightcore, vaporwave and custom speed all use the `timescale` filter, so only one can be active.
- Changing speed also changes how fast `player.position` moves.

Read the [filters guide](../../guides/filters/) for every method.
