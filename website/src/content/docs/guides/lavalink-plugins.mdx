Raya has built-in support for popular Lavalink plugins, and raw access for everything else.

<Tabs>

    // Lyrics for the current track (null when none were found)

## Checking what a node supports

Raya fetches each node's `/v4/info` when it connects:

```js
const node = raya.getNode('main');
node.hasPlugin('lavasrc-plugin');
node.hasSource('spotify');
node.hasFilter('timescale');
node.info?.version.semver;
```

## Plugin events

Known plugin events have their own names (above). Every non-core event is also emitted as `pluginEvent`:

```js
raya.on('pluginEvent', (player, event) => {
  if (event.type === 'MyPluginEvent') console.log(event);
});
```

## Custom endpoints

`node.rest.request` sends authenticated requests to any endpoint, with timeouts, safe retries for `GET`, and `RestError` on failure:

```js
const data = await node.rest.request('GET', '/v4/my-plugin/status');
await node.rest.request('POST', '/v4/my-plugin/thing', { body: { enabled: true } });
```

## Plugin filters

```js
await player.filters.setPluginFilter('echo', { /* shape defined by the plugin */ });
```
